# STI Vio-Log frontend

React 19.2.8/Vite 8.2.1 application, using JavaScript/JSX, custom CSS, History API routing, React hooks and native fetch. Node 24.x/npm 11.x are required.

From this directory, install with `npm.cmd ci`, copy `.env.example` to a private `.env`, configure local `VITE_API_URL`/Google client, and run `npm.cmd run dev`. Production browser API/realtime requests use the same-origin proxy generated by `vercel.mjs`; previews require an isolated API. Do not put server secrets in VITE variables.

Checks: `npm.cmd test`, `npm.cmd run lint`, `npm.cmd run build`, `npm.cmd run audit:performance`. October 10, 2026: 438 tests, lint and build/asset budget passed. These are Node/helper/source/SSR checks, not authenticated browser or physical-camera acceptance. Vercel Analytics is installed but not loaded.
